Reproducible EEG Data & Signal Pipeline

01 / Zero Leakage Split

Strict Patient-Wise Split (16 / 4 / 4)

Random window splitting causes severe leakage — the model memorizes patient background. We partitioned all 24 CHB-MIT patients strictly by person, protected by check_split_leakage.py:

Training — 16 Patients (~143 Seizures)67%
Validation — 4 Patients (chb11, 12, 19, 20)16.5%
Test — 4 Unseen Patients (chb21, 22, 23, 24)16.5%
02 / Hardware-Aware Filtering

Why 0.5–50 Hz Eliminated the 60 Hz Notch Filter

The CHB-MIT dataset was recorded in Boston, USA — the raw EEG has a sharp 60 Hz powerline spike.

By cutting off at 50.0 Hz, the mains hum is attenuated automatically — no dedicated 60 Hz Notch filter needed, saving valuable MCU cycles for embedded inference.

We also kept raw amplitude intact (no Z-score normalization) so high-voltage seizure spikes are never artificially flattened before feature extraction.

03 / SzCORE Windowing Policy

2.0-Second Windows & Overlap Rules

Continuous EEG → 2.0s windows, 50% overlap → one decision per second.

Training (SzCORE >50%): A window is Class 1 only if >1.0s overlaps a clinical seizure annotation.
Evaluation (OVLP >0%): Any overlap counts — early onset detections are rewarded.

04 / Feature Extraction

22 Channels × 7 Features = 154 Inputs

7 lightweight features extracted per channel:

5 Welch PSD bands: Delta (0.5–4), Theta (4–8), Alpha (8–13), Beta (13–30), Gamma (30–50 Hz).
2 Time-Domain: Line Length (sharpness detector) + Variance (Hjorth Activity).

Spiking Neural Network — Architecture & Silicon Reality

LIF SNN trained on 349:1 imbalance, 100% clinical event recall, and compressed to 27.4 KB for implant-grade deployment.

Core Discovery — Window vs. Clinical Event Level

Why 23% Window Recall = 100% Clinical Recall

A seizure lasts 20–60 seconds — that is 20–60 consecutive 2s windows. Missing some windows while catching any early window is enough to trigger therapy. The clinical metric that matters is: did we detect this seizure event at all?

SNN Clinical Event Recall (46 / 46)100.00%
Random Forest Event Recall (45 / 46)97.83%
SNN Isolated Window Recall (misleading metric)23%
Architecture & Training Strategy

154 → 128 → 64 → 2 LIF Network

Rate Spike Encoding: Features scaled to [0,1] via frozen training-set Min-Max bounds, then converted to binary spikes over T = 25 simulation steps.

LIF Neurons (β = 0.9): Membrane potential leaks, accumulates synaptic input, fires when threshold exceeded. Spike-count readout over 25 steps.

Defeating 349:1 Imbalance: Undersampling rejected to preserve interictal diversity. Weighted BCE Loss outperformed Focal Loss. Early stopping locked best checkpoint.

Why This Happens

The LIF SNN integrates distributed synaptic current across all 154 inputs (22 ch × 7 features). When channels are missing, the total excitatory drive drops below the membrane firing threshold — fewer neurons spike, and the output sum falls short of the seizure decision boundary. This motivates the hardware lead-off detection system in Epic E.
